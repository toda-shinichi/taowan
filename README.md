# 大澳灣文化工作團 (Taowan Cultural Working Group)

> 「大澳灣」是台灣住民堅忍卓絕的精神表徵。長年致力於原住民樂舞傳揚與國際交流，並落實偏鄉醫療、車輛、身障與弱勢族群關懷服務。

---

## 🌐 網站架構與頁面導覽

- **首頁 (`index.html`)**：核心精神、三大深耕支柱、歷年行腳精選、文化圖輯與活動動態。
- **關於我們 (`about.html`)**：
  - 「大澳灣」精神表徵與立案由來（西拉雅平埔族台窩灣由來、南島語族血緣考證、歷史活動相片）。
  - 團隊成立之緣由與經歷（原住民樂舞傳承、加拿大與日本北海道愛努族國際交流）。
  - 社服工作路迢遙（1999 譚維義院長感召、921 大地震轉型、20 餘年偏鄉行腳）。
- **公益行腳資料庫 (`charity.html`)**：
  - 歷年 34 篇深度專案報導庫（含真實年份與高解析度照片紀錄）。
  - 複合分類篩選：救護與交通車輛、醫療與輔具設備、聖嘉民長照專案、主愛之家反毒專案、弱勢與長者關懷、愛心物資送暖、文化培力與教育。
  - 歷年足跡總年表 (2008 ~ 2025)。
- **活動紀實 (`activity.html`)**：文化交流與樂舞展演大圖相簿，內建全螢幕燈箱輪播。
- **訊息分享 (`message.html`)**：最新年度活動訊息與公告。
- **鼓勵與支持 (`support.html`)**：100% 專款專用承諾、郵政劃撥與兆豐銀行捐款專用帳戶（可抵扣所得稅額）。
- **聯絡我們 (`contact.html`)**：組織資訊、電話、傳真、信箱（表單直通 `wisrain@ms34.hinet.net`）與 Google Maps 地圖。

## 🚀 部署至 GitHub Pages

本專案為純靜態 (Pure Static HTML5 / CSS3 / Vanilla JS) 架構，無需任何建置步驟：
1. 進入 GitHub Repository 的 **Settings** -> **Pages**。
2. **Branch** 選擇 `main`，資料夾選擇 `/ (root)`。
3. 點擊 **Save**，即可發布上線！
